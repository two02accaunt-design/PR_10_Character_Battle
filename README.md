# Практична робота №10 — Класи та модулі JavaScript

## Гра «Герой проти монстра»

### Запуск
Оскільки проєкт використовує JavaScript-модулі, відкрийте папку у VS Code та запустіть `index.html` через розширення Live Server.

### Файли
- `index.html` — структура сторінки.
- `style.css` — оформлення.
- `character.js` — клас Character для створення персонажів.
- `utils.js` — допоміжна функція випадкового урону.
- `main.js` — основна логіка гри та імпорт модулів.

### Використано
- класи та конструктор;
- створення двох об'єктів одного класу;
- методи `takeDamage()`, `heal()` та `isAlive()`;
- модулі `import` та `export`;
- обробники подій JavaScript.
